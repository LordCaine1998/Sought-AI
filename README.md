Sought AI is an AI chat platform built for coding, research, and everyday questions. Its flagship model, Card 3, is a 120B-parameter mixture-of-experts model tuned for harder reasoning and coding tasks. The platform includes real-time sync, message search, reply threading, chat export, and a free tier that requires no payment details to get started. Tiered plans unlock additional models and themes for users who want more.
